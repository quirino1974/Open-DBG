REQUISITI DI DBGUARDIAN
Autore: Quirino Scaramastra

SISTEMA
-------

- Linux o macOS con Docker Engine o Docker Desktop.
- Windows 10 o 11 con Docker Desktop e il backend WSL 2 attivo (impostazione predefinita).
  Lo script avvia.ps1 richiede PowerShell 5.1 o successivo, già presente in Windows.
  Se PowerShell blocca gli script, eseguire una volta: Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
- Docker Engine 24 o successivo, o Docker Desktop, con Docker Compose v2 (comando "docker compose").
- RAM: almeno 4 GB liberi per il monitor, il database del monitor e la build.
  La build dell'immagine usa Node 22 e Maven: il primo avvio richiede alcuni minuti.
- Disco: circa 3 GB per le immagini, più lo spazio del volume del database (db_data).

IMMAGINI E DOWNLOAD
-------------------

Il primo avvio scarica da internet:
- mariadb:11.4 (database del monitor);
- node:22-alpine, maven:3.9-eclipse-temurin-21 ed eclipse-temurin:21-jre (build).

Il container del monitor deve poter raggiungere i server monitorati sulla porta
del loro database, e l'API del provider IA se la si abilita:
- api.anthropic.com e api.openai.com (porta 443), solo con il commento IA attivo;
- api.telegram.org (porta 443), solo con le notifiche Telegram attive.

PORTE
-----

- 8080: interfaccia web del monitor (configurabile nel docker-compose.yml).
- 3306, 5432, 1433 e simili: porte dei database monitorati, da raggiungere dal container.

CONFIGURAZIONE
--------------

- File .env con APP_SECRET_KEY obbligatoria: lo crea lo script di avvio (vedere README.txt).
- DB_ROOT_PASSWORD, DB_PASSWORD: facoltative; il default serve solo per il laboratorio.

VERSIONI TESTATE
----------------

- MySQL 8.4 e MariaDB 11.4 con cluster InnoDB e Galera.
- PostgreSQL 17 con repliche in streaming.
- SQL Server 2022.
