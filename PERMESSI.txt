PERMESSI DEGLI UTENTI DI MONITORAGGIO
Autore: Quirino Scaramastra

Il monitor deve solo leggere. Nessun controllo esegue scritture o DDL.
Le query dei piani di esecuzione (EXPLAIN) non vengono eseguite: per le scritture
(UPDATE, DELETE, INSERT ... SELECT) viene pianificata la sola parte di lettura.


MYSQL 8.4 E MARIADB 11.4
------------------------

Creare un utente dedicato, invece di usare root:

    CREATE USER 'dbguardian'@'%' IDENTIFIED BY '<password>';
    GRANT PROCESS, REPLICATION CLIENT, SELECT ON *.* TO 'dbguardian'@'%';
    FLUSH PRIVILEGES;

Senza performance_schema attivo non ci sono query lente.

Permessi per controllo:
- connessioni attive e query attive: PROCESS
- query più lente: SELECT su performance_schema (performance_schema=ON)
- piano di esecuzione: SELECT sulle tabelle della query
- utenti e scadenza password: SELECT su mysql.user
- replica: REPLICATION CLIENT
- indici inutilizzati: SELECT su sys e performance_schema

MariaDB: performance_schema è disattivato di default. Va attivato nella
configurazione del server con performance_schema=ON.


POSTGRESQL 17
-------------

    CREATE ROLE dbguardian_mon LOGIN PASSWORD '<password>';
    GRANT pg_monitor, pg_read_all_settings, pg_read_all_stats TO dbguardian_mon;

Per ogni database monitorato:

    GRANT CONNECT ON DATABASE <database> TO dbguardian_mon;
    GRANT USAGE ON SCHEMA public TO dbguardian_mon;
    GRANT SELECT ON ALL TABLES IN SCHEMA public TO dbguardian_mon;
    ALTER DEFAULT PRIVILEGES IN SCHEMA public GRANT SELECT ON TABLES TO dbguardian_mon;

Permessi per controllo:
- connessioni, query attive e transazioni inattive: pg_monitor (pg_stat_activity)
- query più lente: estensione pg_stat_statements installata nel database collegato
- piano di esecuzione: SELECT sulle tabelle della query
- scadenza ruoli: pg_roles, leggibile da tutti

Per le query lente, installare l'estensione in ogni database collegato:

    CREATE EXTENSION pg_stat_statements;

Richiede shared_preload_libraries = 'pg_stat_statements' e un riavvio del server.


SQL SERVER 2022
---------------

A livello di server:

    CREATE LOGIN stats_reader WITH PASSWORD = '<password>', CHECK_POLICY = ON;
    GRANT VIEW SERVER STATE TO stats_reader;
    GRANT VIEW SERVER PERFORMANCE STATE TO stats_reader;
    GRANT VIEW ANY DEFINITION TO stats_reader;

Per ogni database monitorato:

    USE <database>;
    CREATE USER stats_reader FOR LOGIN stats_reader;
    ALTER ROLE db_datareader ADD MEMBER stats_reader;
    GRANT VIEW DATABASE STATE TO stats_reader;
    GRANT SHOWPLAN TO stats_reader;

Per evitare la chiusura dei database e l'azzeramento dei contatori degli indici:

    ALTER DATABASE <database> SET AUTO_CLOSE OFF;

Permessi per controllo:
- connessioni, query attive e risorse: VIEW SERVER STATE e VIEW SERVER PERFORMANCE STATE
- query più lente: VIEW SERVER PERFORMANCE STATE
- utenti e scadenza login: VIEW ANY DEFINITION
- frammentazione e utilizzo indici: VIEW DATABASE STATE
- piano di esecuzione: SHOWPLAN e SELECT sulle tabelle
