Autore: Quirino Scaramastra


2026-11-05 · versione Alfa 0.2
------------------------------

- MongoDB 8.0: stato del replica set, ritardo, oplog, operazioni lunghe, cache WiredTiger,
  connessioni, dimensione dei database e query lente con il profiler.
- Funzioni IA on demand: spiegazione di un evento o di una query, suggerimenti per una query,
  riepilogo degli incidenti, domande sul monitoraggio e rilevazione di anomalie. Solo testo.
- Commento IA con Ollama locale, oltre ad Anthropic e OpenAI.
- Metriche dell'host (CPU e memoria) da node_exporter, facoltative per ogni server.
- Pulsante "Termina sessione" per le transazioni bloccate, con un'utenza separata che ha solo
  il permesso di terminare sessioni.
- "Sospendi monitoraggio": il server non viene connesso, né rilevato né incluso nell'Insight.
- Catalogo dei controlli per tecnologia: un controllo deselezionato non viene eseguito.
- Statistiche su indici e database, e gestione dei siti nelle impostazioni (solo amministratore).
- Manuale dentro l'applicazione.
- Il file docker-compose.yml legge le password dal file .env; i valori di laboratorio sono documentati nel README.
- La rete Docker del monitor è solo quella del progetto: per i server in un'altra rete vedere README.txt.


2026-11-03 · versione Alfa 0.1
------------------------------

Prima versione pubblicata come laboratorio.

- Monitoraggio via JDBC in sola lettura di MySQL 8.4, MariaDB 11.4, PostgreSQL 17 e SQL Server 2022.
- Dashboard con server, cluster, repliche e stati; topologia dei cluster InnoDB e Galera.
- Indicazione del nodo candidato al ripristino per i cluster Galera fermi.
- Insight giornaliero con punteggio, controlli, esiti e raccomandazioni.
- Commento IA opzionale con Anthropic, OpenAI o entrambi.
- Notifiche Telegram con conferma di presa visione.
- Ricerca di un database per nome su più server.
- Piano di esecuzione (EXPLAIN) delle query, senza eseguirle.
- Utenti con profili, server assegnati, cambio obbligatorio della password al primo accesso
  e limite ai tentativi di accesso.
- Cifratura delle password dei server e delle chiavi API con APP_SECRET_KEY.
