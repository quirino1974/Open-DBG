OPEN-DBG REQUIREMENTS
Author: Quirino Scaramastra
Alpha version: not for production use.

SYSTEM
------

- Linux or macOS with Docker Engine or Docker Desktop.
- Windows 10 or 11 with Docker Desktop and the WSL 2 backend enabled (default setting).
  The avvia.ps1 script requires PowerShell 5.1 or later, already present in Windows.
  If PowerShell blocks scripts, run once: Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
- Docker Engine 24 or later, or Docker Desktop, with Docker Compose v2 ("docker compose" command).
- RAM: at least 4 GB free for the monitor, the monitor database and the build.
  The image build uses Node 22 and Maven: the first start takes several minutes.
- Disk: about 3 GB for the images, plus the space of the database volume (db_data).

IMAGES AND DOWNLOADS
--------------------

The first start downloads from the internet:
- mariadb:11.4 (monitor database);
- node:22-alpine, maven:3.9-eclipse-temurin-21 and eclipse-temurin:21-jre (build).

The monitor container must reach the monitored servers on their database port, and the
provider APIs if you enable them:
- api.anthropic.com and api.openai.com (port 443), only with AI enabled;
- api.telegram.org (port 443), only with Telegram notifications enabled;
- Ollama on the host machine (port 11434 by default), only with the Ollama provider;
- node_exporter on the hosts, only if you enter its address in the server settings.

PORTS
-----

- 8080: the monitor web interface (configurable in docker-compose.yml).
- 3306, 5432, 1433, 27017 and similar: ports of the monitored databases, reachable from the container.

CONFIGURATION
-------------

- An .env file with a mandatory APP_SECRET_KEY: the start script creates it (see README.en.txt).
- DB_ROOT_PASSWORD, DB_PASSWORD: optional; the default is only for the lab.

SERVER ACCOUNTS
---------------

Each monitored server needs a read-only account. The minimum permissions for each technology
are in PERMESSI.en.txt. The optional account for terminating blocking sessions is separate and
is only needed if you want to use that button.

TESTED VERSIONS
---------------

- MySQL 8.4 and MariaDB 11.4 with InnoDB and Galera clusters.
- PostgreSQL 17 with streaming replicas.
- SQL Server 2022.
- MongoDB 8.0 with replica set.
